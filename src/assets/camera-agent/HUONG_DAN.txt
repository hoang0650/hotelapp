========================================
  PHHotel Camera Agent — Hướng dẫn nhanh
  (Dành cho người không rành máy tính)
========================================

MỤC ĐÍCH
  Phần mềm này chạy trên máy tính trong khách sạn để kết nối
  camera (qua mạng nội bộ) với hệ thống PHHotel trên internet.

BẠN CẦN
  1) Một máy tính Windows bật suốt khi muốn xem camera từ xa
  2) Internet ổn định
  3) Node.js (miễn phí) — BAT_DAU tự kiểm tra (PATH, Program Files, NVM).
     Chỉ mở trang cài khi thật sự không tìm thấy Node.

CÁCH CHẠY (3 BƯỚC)
  Bước 1: Giải nén file ZIP vừa tải vào thư mục dễ nhớ
          (ví dụ: Desktop\PHHotel-Camera-Agent)
          ★ QUAN TRỌNG: phải GIẢI NÉN thật sự ra ổ đĩa.
            KHÔNG bấm đúp BAT_DAU.bat ngay trong cửa sổ WinRAR/ZIP
            (sẽ lỗi: Cannot find module ...\Rar$DI...\server.js).

  Bước 2: Mở thư mục ĐÃ GIẢI NÉN, bấm đúp file   BAT_DAU.bat
          - Lần đầu có thể chờ vài phút (tự cài thư viện)
          - Để cửa sổ đen mở — ĐỪNG đóng cửa sổ này

  Bước 3: Khi thấy dòng có chữ:
            camera-agent ProxVN public URL: https://....
          → Copy nguyên dòng https://...
          → Vào PHHotel → Cấu hình Camera → Agent (On-Prem)
          → Dán vào ô Agent URL → Lưu / Test Agent

NẾU KHÔNG THẤY DÒNG https://
  - Kiểm tra internet
  - Đóng BAT, mở lại BAT_DAU.bat
  - Hoặc dùng nút "Quét lại agent" trong PHHotel (cùng máy / mạng)

DỪNG CHẠY
  Trong cửa sổ đen: bấm Ctrl + C, rồi Enter nếu được hỏi.
  Hoặc đóng cửa sổ.

NẾU BÁO LỖI "EADDRINUSE" / CỔNG 8787
  Nghĩa là Camera Agent đang chạy sẵn (cửa sổ cũ còn mở).
  → Không cần mở thêm: dùng cửa sổ cũ.
  → Muốn chạy lại: đóng cửa sổ Camera Agent cũ, rồi bấm lại BAT_DAU.bat.
  Bản BAT_DAU mới sẽ tự báo "đã đang chạy" hoặc tự đóng tiến trình cũ.

NẾU THẤY "[proxvn] Không tìm thấy ProxVN client binary"
  Cần file:  bin\proxvn-windows-amd64.exe  (trong thư mục vừa giải nén).
  → Tải lại ZIP từ Kho tài liệu (bản có ProxVN), giải nén đè lên.
  → Đóng cửa sổ BAT cũ, bấm lại BAT_DAU.bat.
  Khi OK sẽ thấy: camera-agent ProxVN public URL: https://....

LƯU Ý
  - Máy chạy BAT phải cùng mạng với camera (hoặc truy cập được RTSP)
  - Không gửi file .env cho người lạ nếu bạn đã đặt mật khẩu token
  - Cần hỗ trợ: liên hệ kỹ thuật PHHotel / hotro@phhotel.vn
