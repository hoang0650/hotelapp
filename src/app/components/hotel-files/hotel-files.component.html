Camera Agent — chạy trên máy khách sạn

Tải về, giải nén, bấm đúp BAT_DAU.bat. Không cần biết lập trình.

  1. Tải ZIP → giải nén vào máy tính Windows trong khách sạn.
  2. Bấm đúp BAT_DAU.bat (lần đầu chờ cài vài phút, để cửa sổ mở).
  3. Copy dòng https://... hiện ra → dán vào Cấu hình Camera → Agent URL.

Chi tiết xem file HUONG_DAN.txt trong gói. Có thể tải từng file bên dưới nếu không dùng được ZIP.
